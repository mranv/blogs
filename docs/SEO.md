# SEO — what is wired, and how to check it

Audited 2026-11-15 against the checklists in `AgriciDaniel/claude-seo` (technical, schema,
GEO, sitemap). That repo was used as a reference only; nothing from it is installed here.

## Check

```bash
pnpm build   # astro build, pagefind, node scripts/og/build.mjs dist, node scripts/seo-audit.mjs dist
```

The audit is the last step of the build, so it also gates the Cloudflare Pages deploy. Exits 1 on a hard failure (og:image that 404s, invalid JSON-LD, sitemap URL with no page,
post without Article schema). Everything else is a count to watch, with examples
(`N=300` prints more).

## Landmines

- **og:image never points into `src/assets`.** Those files get a content-hashed name and have
  no stable URL; pointing og:image at `assets/images/gainsaheb.jpeg` was a 404 on all 1,687
  pages. `public/avatar.jpg` is a copy of `src/assets/images/gainsaheb.jpeg`: replace both
  when the photo changes.
- **Social cards exist only in `dist/`.** `Layout.astro` emits the `/og/<path>.png` URL,
  `scripts/og/build.mjs` reads that tag from the built HTML and writes the file. Running
  `astro build` alone gives pages whose og:image is a 404; always use `pnpm build`.
- **Card fonts are atlases, not font files.** The Pages builder has no Space Grotesk or Space
  Mono. Adding an ASCII piece with new glyphs means adding them to `make-atlas.mjs` and
  re-running it, or they render as blank cells.
- **The duplicate-post rule lives in two places** (`getStaticPaths` in the slug page and
  `duplicateUrls` in `astro.config.mjs`): shortest slug wins, ties alphabetical. Change both.
- **The author is one entity.** Person JSON-LD has `@id` `<site>#person`; WebSite, BlogPosting,
  ProfilePage and ProfessionalService reference that id. Do not paste a second full Person node.
- **Exactly one `<h1>` per post.** The post title renders as `<h1>` only when the markdown
  body has no `# ` heading of its own.
- **Keep `/archive/` under 2 MB.** Googlebot reads the first 2 MB of HTML. The archive list is
  serialised as island props; `getSortedPostsList` passes only the fields the panel reads.
- **No schema placeholders.** A fake value (`alumniOf: "Professional Institution"`) is worse
  than a missing property.

## Known gaps (not fixable by a template change)

- Five posts exist twice under two slugs. The copies are canonicalised and left out of the
  sitemap automatically, but they are still built: deleting one of each pair is cleaner.
- About 440 `<title>`s are over 65 characters because the post titles themselves are long.
- Content-Security-Policy is a baseline only (`public/_headers`): no `script-src`, because the
  theme script, JSON-LD and islands are inline and would need nonces or hashes.
- Off-site: Search Console and Bing Webmaster verification and sitemap submission, a custom
  domain instead of `pages.dev`, backlinks. None of it can be done from this repo.
